# Офлайн-карты на ESP32-S3 и Waveshare 7.5″ B/W/Red

Откройте **offline_map.ino** в Arduino IDE. Файлы `MapApp.h`, `Buttons.h`,
`MapIndex.h`, `MapRender.h`, `Route.h` и `GpsTrack.h` должны оставаться рядом
со скетчем.

## Arduino IDE

Плата: **ESP32S3 Dev Module**, пакет **esp32 by Espressif Systems**.
Контрольная конфигурация сборки использует Arduino-ESP32 **2.0.17**.

- Flash Size: **16MB**.
- Flash Mode: **QIO**, Flash Frequency: **80MHz**.
- PSRAM: **OPI PSRAM**.
- USB CDC On Boot: **Enabled**.
- USB Mode: **Hardware CDC and JTAG**, если этот пункт доступен.
- Partition Scheme: схема для **16MB**, например Default 16MB.
- CPU Frequency: **240MHz**.
- Serial Monitor: **115200**.

Установите в менеджере библиотек:

| Библиотека | Версия контрольной сборки |
|---|---:|
| GxEPD2 | 1.6.9 |
| Adafruit GFX Library | 1.12.6 |
| Adafruit BusIO | 1.17.4 |
| ArduinoJson | 7.4.3 |
| U8g2_for_Adafruit_GFX | 1.8.0 |

ArduinoJson 6 не подходит: используется API распределителя памяти версии 7.
Кириллический шрифт: `u8g2_font_6x13_t_cyrillic`.

## Подключение

| Функция | GPIO |
|---|---:|
| EPD MOSI / CLK | 3 / 6 |
| EPD PWR / CS / DC | 7 / 18 / 21 |
| EPD RST / BUSY | 38 / 42 |
| SD CMD / D0 / CLK | 39 / 40 / 41 |
| Кнопочная лестница | 2 |

HAT Rev2.3: Display Config **A / 3R**, Interface **0 / 4-line SPI**;
VCC 3.3V, общий GND. Подтяжка ADC: внешние 10 кОм к 3.3V.
GPIO1, GPIO46, встроенный LCD, IMU, WS2812 и GPS-выводы не используются.

## SD и браузер

Поместите GeoJSON FeatureCollection в `/maps/`, например `/maps/map1.geojson`.
Рекомендуемая файловая система — FAT32. Корневой файл проекта
`map1.geojson` нужно самостоятельно скопировать в эту папку на SD.

При запуске появляется список до 256 файлов `.geojson` из `/maps/`.
Подпапки не просматриваются. SW1/SW2 выбирают файл, SW3 открывает,
SW4 перечитывает список; SW5/SW6 переходят по страницам.
Одновременно открыта одна карта. На SD нужны свободное место и возможность
записи для индекса. При ошибке сообщение появляется внизу браузера,
подробности — в Serial.

Первое открытие создаёт рядом `.gidx`. При последующих открытиях скетч
проверяет содержимое GeoJSON и индекс; при необходимости перестраивает.
Полное чтение исходного файла для проверки происходит **при открытии**,
а перемещения используют компактный индекс и читают только видимые Feature.
Индекс сначала записывается во временный файл; незавершённый индекс не
используется. Каждая геометрия разбирается отдельно в PSRAM.

## Кнопки карты

| SW | ADC | Нажатие |
|---|---:|---|
| 1 | 0 | Вверх / север |
| 2 | 1915 | Вниз / юг |
| 3 | 872 | Вправо / восток |
| 4 | 482 | Влево / запад |
| 5 | 272 | Масштаб + |
| 6 | 135 | Масштаб − |
| 7 | 43 | Инверсия при отпускании |

Удержание SW7 **1 секунду** возвращает в браузер без инверсии.
Удержание SW1 включает или выключает слежение за GPS. Удержание SW2
начинает или завершает запись экранного и файлового трека. Состояния показаны
в нижней строке как `F:on/off` и `T:on/off`. SW3/SW4
повторяются через 600 мс, затем раз в 250 мс. Шаг — четверть
области карты (160×114 пикселей). Очередь на 256 событий обслуживается
отдельной задачей и работает во время обновления дисплея. Накопившиеся
движения применяются перед следующим кадром. Переполнение явно выводится
в Serial. Одновременные нажатия нескольких кнопок лестница не различает.

При проверке/создании индекса удержанием SW7 можно отменить открытие;
обычные навигационные нажатия на этом этапе игнорируются. При отрисовке
карты и обновлении дисплея они сохраняются в очереди. Выход во время
отрисовки выполняется после завершения текущего кадра.

Начальный масштаб — **Z13**. Без GPS fix карта открывается по центру границ
выбранного GeoJSON, а маркер находится в центре экрана. При fix используются
реальные координаты UART GPS на GPIO16/17, 38400 бод. При запуске модулю
u-blox M10 отправляется UBX-настройка периода навигации 10 секунд. Fix считается
устаревшим через 25 секунд без корректного GGA/RMC. При включённом слежении
карта перемещается, когда маркер входит в крайние 10% области, и переносит
маркер к противоположным 10%. При выключенном слежении положение карты не
зависит от GPS.

`TRACK ON` создаёт `/maps/track_NNNN.geojson.part`, пишет принятые точки
потоково и сразу сбрасывает их на SD. Перемещения короче 3 метров от предыдущей
точки отбрасываются. `TRACK OFF` закрывает GeoJSON, переименовывает его в
`track_NNNN.geojson` и стирает линию трека с экрана. Итоговое значение
«Пройдено» остаётся до следующего `TRACK ON`. Незавершённый `.part`
остаётся на карте памяти после неожиданного отключения питания.

## Wi-Fi и системное меню

Перед сборкой скопируйте `secrets.example.h` в `secrets.h` и укажите в нём
имя и пароль своей Wi-Fi сети. Файл `secrets.h` исключён из Git.

После запуска Wi-Fi выключен. Включите его из системного меню; полученный
DHCP-адрес показывается в правой панели и в системном меню.
На этом IP доступен HTTP-браузер: список файлов `/maps/`, загрузка GeoJSON,
скачивание и удаление файлов. При удалении соответствующий `.gidx` также
удаляется. После загрузки список карт перечитывается.

Удержание SW7 в браузере карт открывает системное меню. В нём SW1/SW2
переключают пункты, SW3 активирует Wi-Fi, диагностику NMEA, тестовый маршрут
или возврат, а SW4 возвращает к списку.
При выключении Wi-Fi отключается STA и HTTP-сервер; повторное включение
запускает подключение к настроенной сети заново.

## Изображение и обновления

Область карты — 772×456; справа 28 пикселей занимает компактная панель
пиктограмм, снизу —
строка состояния. Проекция — Web Mercator, север сверху.

Вода и здания рисуются до дорог. Реки отображаются чёрным, дороги — серым
штрихом шириной 3 пикселя. Здания имеют серую
заливку и контур. Внутренние кольца полигонов остаются отверстиями.
После геометрии выводятся крупный GPS-маркер и названия населённых пунктов с белой
подложкой и проверкой пересечений надписей. Инверсия меняет весь экран,
включая фон текста, и один раз выводит воду красным. Следующее быстрое
обновление стирает красный слой; дальнейшие кадры снова чёрно-белые. Серый —
узор чёрных и белых точек, не физические градации серого данной панели.

Драйвер: **GxEPD2_750c_GDEW075Z08**. При старте выполняется медленное
полное обновление белым, которое очищает панель и согласует опорный кадр.
Все последующие обновления выполняются через
`display.displayWindowBW(0, 0, 800, 480)`: передача, `refresh_bw()`,
синхронизация предыдущего кадра. `GxEPD2_750c_Z08` не является заменой
этому драйверу: специального B/W API у него нет.

Контроллер сохраняет RAM между кадрами; отключаются только высокие
напряжения методом `powerOff()`. `hibernate()` и отключение GPIO7 между
кадрами не применяются. BUSY-таймаут останавливает работу и выводит ошибку
в Serial. Фактическую скорость и остаточные следы необходимо проверить
на подключённой панели; сборка программы этого не проверяет.

При загрузке показываются этапы и процент; промежуточные экраны появляются
не чаще чем через 4 секунды после завершения предыдущего обновления,
либо при смене этапа. Во время первого полного очищения текст ещё не виден.
Во время чтения видимых объектов уже накопленная геометрия периодически
выводится на экран отдельным быстрым кадром; после завершения выполняется
финальный кадр с подписями и прицелом.

## Проверка сборки без Arduino IDE

Дополнительный `platformio.ini` собирает тот же `.ino`:

```powershell
pio run -d arduino/offline_map
```

Прошивка устройства автоматически не выполняется.
